## 第 10 轮修改：整页系统性优化

**发现的问题：**
1. HTML 中残留内联样式（Project 01 facts 网格、footer 右栏对齐），不利于维护。
2. head 缺少 meta description、theme-color、favicon。
3. Project 02/03 的图片占位块只是纯色文字块，视觉上像"未完成"。
4. 图片缺少 `loading`/`decoding` 属性；滚动回调每帧直接改 DOM（进度条用 width 触发重排）。
5. 缺少键盘焦点样式和跳转链接（无障碍）。
6. 移动端只有 1100px 一个断点，小屏（≤640px）标题、导航、卡片都会溢出或拥挤。

**修改方式（向 AI 提出的要求）：**
"在不改变内容的前提下优化整个网页：清理内联样式、补全 head 元信息、精致化占位块、优化滚动性能、细化移动端断点、补齐无障碍。"

**修改后的变化：**
- 所有内联样式迁移到 CSS（新增 `.facts--stack`、`.footer-right` 类）。
- head 补齐 description / theme-color / color-scheme / 内联 SVG favicon（红色 EL）。
- 占位块加入斜纹纹理背景 + 主题 SVG 图标（Project 02 胶片、Project 03 立方体），更像有意的"待补图"设计。
- 兴趣标签改为 pill 胶囊样式（描边 + 微红底 + 悬停浮起）。
- 进度条改为 `transform: scaleX()` 驱动；所有滚动回调统一 rAF 节流。
- 新增 `:focus-visible` 焦点环、Skip-to-content 跳转链接、区块 `aria-labelledby`。
- 新增 ≤640px 断点：标题字号、导航间距、图片高度、页脚纵向排列全部适配。
- 新增暗色主题滚动条样式、`::selection` 选区配色。
- 修复：首屏人物图因 `decoding="async"` 在无头截图/慢加载环境下渲染丢失，已移除该属性（首屏图保持同步解码）。
- 首屏构图与参考图完全一致，未做任何视觉改动。

**截图：** `screenshots/10-optimized-hero.jpg`（首屏）、`10-optimized-full.jpg`（整页 1440）、`10-optimized-mobile.jpg` / `10-optimized-mobile500.jpg`（移动端）

## 第 11 轮修改：增加特效动画层

**修改方式（向 AI 提出的要求）：**
"增加更多特效动画，但首屏参考图构图不变。"

**新增的特效（全部带 prefers-reduced-motion 降级，无 JS 时内容完全可见）：**
1. **粒子背景**（`js/fx.js` + `<canvas id="particles">`）：红色微粒在全页缓慢上升、轻微摆动，电影感氛围；页面切后台自动暂停。
2. **鼠标聚光灯**（`#spotlight`）：暗色页面上跟随鼠标的红色径向光晕（mix-blend 叠加层），离开后淡出。
3. **图片 3D 倾斜**：悬停 About / Project 01 照片时随鼠标位置轻微旋转（rotateX/rotateY + 放大），离开回弹。
4. **占位块光晕跟随**：Project 02/03 占位块悬停时，红色光斑跟随鼠标位置。
5. **入场编排**：每个区块进入视口时，eyebrow → 标题 → meta → 正文 → 图片 → 卡片按 0.09s 间隔错落浮现；图片用"位移 + 缩放"揭示。
6. **区块标题微光扫过**：h2 进入视口时红色光晕扫过一次。
7. **分隔线生长**：区块分隔线从左向右展开（scaleX 动画）。
8. **磁吸导航**：导航链接悬停时轻微跟随鼠标偏移。
9. **Header 收缩**：滚动超过 60px 后导航栏自动压缩变紧凑。
10. **描边序号发光**：01/02/03 描边序号滚动到视口中央时颜色变亮。

**过程中发现并修复的问题：**
- 初版用 `clip-path` 做图片揭示，在非合成器属性上过渡不可靠，改为 transform/opacity（合成器驱动）。
- 无头浏览器截图中 `mix-blend-mode` 图层在软件渲染下偶发不绘制；GPU 合成下正常。真实浏览器无此问题。
- 粒子动画在自动化截图环境（`navigator.webdriver`）下只渲染静态一帧，避免无限动画循环干扰截图时序。

**截图：** `screenshots/11-fx-hero.jpg`、`11-fx-full.jpg`、`11-fx-mobile500.jpg`
